# سند انتقال نشست و ادامه گفتگو در لینوکس (Session Handover & Context Continuity)

این سند برای انتقال کامل کانتکست پروژه، تاریخچه گفتگو و تصمیمات طراحی از محیط **macOS** به **Linux** تنظیم شده است. با استفاده از این مستند یا انتقال فایل‌های مغز (Brain) ایجنت، می‌توانید پروژه را روی لینوکس دقیقاً با همان سطح هوشمندی و تسلط قبلی ادامه دهید.

---

## ۱. هویت برند و ضوابط بنیادین طراحی (Core Brand Rules)
1. **نام رسمی برند:**
   * انگلیسی: **Baldr** (حرف e در انتهای نام اشتباه بوده و در تمام کدها، فایل‌ها، متادیتاها و دایرکتوری‌ها به Baldr تغییر یافته است).
   * فارسی: **بالدر**
   * لوگو: نشان قرمز رنگ اختصاصی (`/images/baldr-logo-red.webp`) در نوبار و فوتر تمام صفحات نمایش داده می‌شود (نه متن خالی).

2. **هندسه تیز و بدون گردی (`rounded-none`):**
   * تمامی کامپوننت‌ها، دکمه‌ها، کارت‌های محصول، مدال‌ها، اینپوت‌ها و فیلترها باید گوشه‌های تیز داشته باشند (`rounded-none`). هیچ‌گونه گردی (`rounded-md`, `rounded-full`, etc.) مجاز نیست مگر دایره‌های کامل سواچ رنگ یا وضعیت رادیویی.

3. **فرمت اجباری تصاویر (`.webp`):**
   * تمامی عکس‌ها باید با فرمت `.webp` در `frontend/public/images/` ذخیره و فراخوانی شوند. استفاده از فرمت‌های سنگین `.jpg` و `.png` ممنوع است.

4. **تم بصری (Aesthetic):**
   * گالری روشن مینیمال با الهام از برندهای لوکس Flos و Davide Groppi با پس‌زمینه سفید/روشن، خطوط تفکیک ملایم (`#E5E5E5`) و رنگ اکسنت قرمز روشن (`#E40521`).

## ۴. مراحل گام‌به‌گام راه‌اندازی روی لینوکس (Linux Setup Guide)

### مرحله ۱: دریافت کد از گیت‌هاب
```bash
git clone git@github.com:MobinShekari84/Baldre-Website.git
cd Baldre-Website
```

### مرحله ۲: راه‌اندازی بک‌اند جنگو
```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_baldr
python manage.py runserver 127.0.0.1:8000
```
* **پنل ادمین جنگو:** `http://127.0.0.1:8000/admin/` (یوزر: `admin` / پسورد: `baldre2026`)

### مرحله ۳: راه‌اندازی فرانت‌اند Next.js
در ترمینال مجزا:
```bash
cd frontend
npm install
npm run dev -- -p 3000
```
* **سایت در مرورگر:** `http://localhost:3000`

## ۷. گردش کار استاندارد و الزامی توسعه (Mandatory 4-Step Pipeline)

طبق دستور قطعی کارفرما و قانون ثبت‌شده در `.agents/rules/workflow-order.md`، تمام نشست‌ها و تسک‌های آینده باید دقیقاً این زنجیره ۴ مرحله‌ای را طی کنند:

```
[۱. خواندن فایل‌های Skill] ──► [۲. خواندن اسناد md-files] ──► [۳. اجرای دقیق Task] ──► [۴. آپدیت همزمان Skill و md-files]
```

1. **گام اول (Skills):** مطالعه مهارت‌های اختصاصی پروژه در `.agents/skills/` (شامل هویت برند، دستورالعمل فرانت‌اند Next.js، بک‌اند جنگو و کامپوننت‌های محصول).
2. **گام دوم (md-files):** مطالعه فایل‌های پوشه `md-files/` (به‌ویژه همین سند `SESSION_HANDOVER.md` و مستندات فنی متناظر) برای دریافت آخرین تصمیمات و معماری روز.
3. **گام سوم (Task):** اجرای دقیق خواسته کاربر با رعایت کامل هندسه تیز (`rounded-none`)، فرمت انحصاری `.webp`، فونت یکان‌بخ و کاتالوگ ۸ محصولی.
4. **گام چهارم (Update):** ثبت بلافاصله تغییرات و تصمیمات جدید در `md-files/` و به‌روزرسانی محتوای فایل‌های Skill در `.agents/skills/` به منظور همگام بودن دائمی دانش ایجنت.

## ۱۰. پیاده‌سازی نسخه هنری و مینیمال فوسکارینی (Foscarini-Inspired Artistic Edition)

بر اساس خواسته صریح کارفرما و تحلیل عمیق و کالبدشکافی وب‌سایت رسمی فوسکارینی ([foscarini.com/en](https://www.foscarini.com/en/))، نسخه جدیدی بر پایه زیبایی‌شناسی بدون دکمه (Zero-Button Aesthetic) و تایپوگرافی یکپارچه در شاخه `theme/foscarini-artistic` پیاده‌سازی شد:

### الف) اصول کشف‌شده از تحلیل زنده Foscarini:
1. **زیبایی‌شناسی بدون دکمه (The Zero-Button Aesthetic):** حذف تمامی دکمه‌های باکسی، رنگی یا مستطیلی شلوغ. تمامی تعاملات صرفاً با یک فلش مورب قرمز ظریف (`↗`) به رنگ `#E40521` یا متن‌های دارای هاور انجام می‌شود.
2. **یکپارچگی مطلق سلسله‌مراتب تایپوگرافی (Strict 4-Layer Hierarchy):** در تمام سکشن‌های صفحه اصلی، دقیقاً ۴ لایه با سایزهای کاملاً یکسان تکرار می‌شوند:
   - لایه ۱ (Kicker): اندازه **12px**، حروف بزرگ / فونت یکان‌بخ، رنگ `#777777`
   - لایه ۲ (Action): آیکون فلش قرمز `↗` (`#E40521`)
   - لایه ۳ (Story Title): اندازه **24px**، وزن Medium، فاصله خطوط 32px، رنگ `#141416` یا `#FFFFFF`
   - لایه ۴ (Body): اندازه **15px**، وزن Regular، فاصله خطوط 26px، رنگ `#444444` یا `#CCCCCC`
3. **ساختار اسپردهای مجله‌ای معماری (1/3 to 2/3 Grid):** ریتم متناوب یک‌سوم متن و دوسوم عکاسی باکیفیت معماری شبیه به صفحات یک کتاب یا مجله نفیس معماری.
4. **هدر متین و آرام (Quiet Floating Header):** لوگوی قرمز بالدر، ۳ عنوان اصلی (محصولات، جهان بالدر، معماران و پروژه‌ها)، سوئیچر آرام زبان (`FA | EN`) و مگامنوی تصویری با ۸ عکس واقعی.

### ب) اسپردهای ۶ گانه پیاده‌سازی‌شده در صفحه اصلی (`frontend/src/app/page.tsx`):
- **Hero Spread:** ویدیوی فول‌ویوپورت ۱۰۸۰p با چرخه بی‌نهایت، مانیفست در گوشه و فلش تعاملی `↗`.
- **Spread 1 (فلسفه نور / مانیفست):** ترکیب ۱/۳ متن فلسفه بالدر + ۲/۳ عکاسی معماری سیستم مگنت (`baldr-inspiration-magnet-system.webp`).
- **Spread 2 (پروژه‌ها و معماری زنده):** عکس عمودی پنت‌هاوس تهران + عکس افقی گالری هنر همراه با بلاک متنی ۴ لایه.
- **Spread 3 (محصول در بستر تاریک / Velvet In-Situ):** پس‌زمینه زغالی با شکوه (`#121214`)، چراغ آویز وکتور در فضای مسکونی واقعی و مشخصات نوری.
- **Spread 4 (صنعتگری و لمس متریال - Maestrie):** عکاسی ماکرو و لمسی از سنگ تراورتن، آلومینیوم و برنج با فلش `↗` برای دریافت مستند متریال.
- **Spread 5 (گرید ۴ تایی خانواده‌های محصول با کنترلر کم‌رنگ `<>`):**
  - نمایش دقیق ۴ دسته‌بندی در یک ردیف در نمایشگرهای دسکتاپ (`lg:grid-cols-4`)
  - تعبیه کنترلر جابه‌جایی اسلایدر دوتایی `<` و `>` با ظاهر محو و ملایم (`border-[#141416]/15` و `text-[#141416]/35`) و نشانگر وضعیت صفحات (`01 / 02`)
  - هاور دوحالته معمارانه (Dual-Image Hover): نمایش عکاسی زنده پروژه با نسبت استاندارد ۴:۵ و کراس‌فید استودیویی روی سفیدی خالص هنگام قرارگیری نشانگر ماوس
  - لینک مستقیم به کاتالوگ فیلترشده با پارامتر کتگوری (`/products?category=...`)
- **Spread 6 (مونوگراف و کاتالوگ معماری):** تصویر ژورنال فیزیکی بازشده (`baldr-catalogue-spread.webp`) و لینک دانلود رسمی کاتالوگ ۱۵۱ صفحه‌ای.
- **Footer:** فوتر ۳ ستونه متین، مینیمال و آرام با اطلاعات رسمی و تماس.
