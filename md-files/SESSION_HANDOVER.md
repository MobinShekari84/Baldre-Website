# سند انتقال نشست و ادامه گفتگو در لینوکس (Session Handover & Context Continuity)

این سند برای انتقال کامل کانتکست پروژه، تاریخچه گفتگو و تصمیمات طراحی از محیط **macOS** به **Linux** تنظیم شده است. با استفاده از این مستند یا انتقال فایل‌های مغز (Brain) ایجنت، می‌توانید پروژه را روی لینوکس دقیقاً با همان سطح هوشمندی و تسلط قبلی ادامه دهید.

---

## ۱. هویت برند و ضوابط بنیادین طراحی (Core Brand Rules)
1. **نام رسمی برند:**
   * انگلیسی: **Baldr** (حرف e در انتهای نام اشتباه بوده و در تمام کدها، فایل‌ها، متادیتاها و دایرکتوری‌ها به Baldr تغییر یافته است).
   * فارسی: **بالدر**
   * لوگو: نشان قرمز رنگ اختصاصی (`/images/baldr-logo-red.webp`) در نوبار و فوتر تمام صفحات نمایش داده می‌شود (نه متن خالی).

2. **هندسه تیز و بدون گردی (`rounded-none`):**
   * تمامی کامپوننت‌ها، دکمه‌ها، کارت‌های محصول، مدال‌ها، اینپوت‌ها و فیلترها باید گوشه‌های تیز داشته باشند (`rounded-none`). هیچ‌گونه گردی (`rounded-md`, `rounded-full`, etc.) مجاز نیست مگر دایره‌های کامل سواچ رنگ یا وضعیت رادیویی.

3. **فرمت اجباری تصاویر (`.webp`):**
   * تمامی عکس‌ها باید با فرمت `.webp` در `frontend/public/images/` ذخیره و فراخوانی شوند. استفاده از فرمت‌های سنگین `.jpg` و `.png` ممنوع است.

4. **تم بصری (Aesthetic):**
   * گالری روشن مینیمال با الهام از برندهای لوکس Flos و Davide Groppi با پس‌زمینه سفید/روشن، خطوط تفکیک ملایم (`#E5E5E5`) و رنگ اکسنت قرمز روشن (`#E40521`).

## ۳. آخرین وضعیت فیچرها و اصلاحات انجام‌شده
1. **جستارهای نوری (Lighting Essays):**
   * رکورد تکراری حذف شد و در اسکریپت `seed_baldr.py` پاک‌سازی خودکار قرار گرفت.
   * ۳ مقاله دارای کارت‌های تعاملی و لینک Next.js به صفحات هدف (`/products`، `/about`، `/professionals`) همراه با دکمه هاور «مطالعه و بررسی / Explore & Read» هستند.

2. **صفحه‌بندی محصولات (Products Pagination):**
   * در نمایشگرهای لپ‌تاپ و بزرگتر: **۹ محصول** در هر صفحه (گرید ۳ تایی در ۳ ردیف).
   * در موبایل: **۴ محصول** در هر صفحه (گرید ۲ تایی در ۲ ردیف).
   * شماره صفحات (1, 2, 3...) و دکمه‌های قبلی/بعدی مستقیماً از طریق Query Param در URL مدیریت می‌شوند (`?page=2`) تا باز کردن در تب جدید یا بوکمارک کردن به سادگی انجام شود.

3. **یکپارچگی دکمه‌ها و عناصر بصری:**
   * دکمه سوئیچ زبان (FA / EN) و دکمه مشاهده کاتالوگ در تمام صفحات یکدست، تیز و فاقد گردی شدند.

## ۴. مراحل گام‌به‌گام راه‌اندازی روی لینوکس (Linux Setup Guide)

### مرحله ۱: دریافت کد از گیت‌هاب
```bash
git clone git@github.com:MobinShekari84/Baldre-Website.git
cd Baldre-Website
```

### مرحله ۲: راه‌اندازی بک‌اند جنگو
```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_baldr
python manage.py runserver 127.0.0.1:8000
```
* **پنل ادمین جنگو:** `http://127.0.0.1:8000/admin/` (یوزر: `admin` / پسورد: `baldre2026`)

### مرحله ۳: راه‌اندازی فرانت‌اند Next.js
در ترمینال مجزا:
```bash
cd frontend
npm install
npm run dev -- -p 3000
```
* **سایت در مرورگر:** `http://localhost:3000`
